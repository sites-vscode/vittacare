Conexão do projeto

Configure URL e chave publicável no arquivo supabase-config.js. Se preferir, você também pode preencher estes campos manualmente.

Use apenas a chave publicável (anon/publishable). Nunca coloque a service_role/secret key no navegador.

Contas são criadas pelo administrador no Supabase. Não há cadastro pelo site.

Abra por HTTPS ou servidor local, como o Live Server do VS Code; o acesso direto via file:// pode impedir a autenticação.
